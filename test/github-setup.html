用 GitHub 保存你的清单

准备一个 GitHub 仓库和只允许访问该仓库的 Token。TofuTodo 会把待办、备忘录和分组直接同步到 GitHub Issues。

工作原理

你将获得一个与 GitHub 个人仓库完全绑定的备忘录，任何时候都可以通过网页或客户端打开。

Token 像密码一样重要。TofuTodo 将它保存在当前浏览器或桌面挂件的本地存储中，并用它直接请求 GitHub API。请只在自己的设备上使用。

首次配置

  1. 创建一个仓库

    登录 GitHub 后新建仓库，例如命名为 tofutodo-data。私人清单建议选择 Private，初始化 README 与否都不影响使用。

    打开 GitHub 新建仓库

  2. 确认 Issues 已开启

    进入仓库的 Settings → General → Features，确认 Issues 已勾选。新建仓库通常默认开启。

  3. 创建 Fine-grained Token

    进入 Token 创建页，填写名称和有效期，然后设置：

    • Resource owner：选择仓库所属账号
    • Repository access：Only select repositories，只选择刚创建的仓库
    • Repository permissions → Issues：Read and write
    • 其他权限保持默认；Metadata 的只读权限会自动附带
    创建 Fine-grained Token

  4. 复制 Token

    点击 Generate token 后立即复制以 github_pat_ 开头的内容。GitHub 离开页面后不会再次完整显示它。

  5. 连接 TofuTodo

    仓库填写 你的用户名/tofutodo-data，Token 粘贴刚生成的内容，然后点击“连接 GitHub”。应用会在首次使用时自动创建需要的标签。

常见问题

提示通常原因
401Token 输入错误、已过期或已被撤销。重新生成 Token 后再连接。
403Token 没有 Issues 写权限，或组织要求管理员批准该 Token。
404仓库名不正确，或 Fine-grained Token 没有选择这个仓库。
无法新增检查仓库是否启用了 Issues，并确认权限是 Read and write。

安全建议

  • 优先使用 Fine-grained Token，不要给整个账号的所有仓库授权。
  • 设置合理的有效期；到期后生成新 Token 并重新连接。
  • 不要截图、发送或提交 Token 到任何 GitHub 仓库。
  • 设备丢失或怀疑泄露时，立即在 GitHub Token 设置页撤销它。
GitHub 的界面可能随时间调整。遇到差异时，以 创建仓库 和 管理 Personal Access Token 官方文档为准。
